# Palette Demo Sequence

This is the quarantined two-minute stage path. The normal app flow should not import or trigger it.

1. Start from a blank canvas.
2. Build a landing page for a robot coffee shop.
3. Let sections paint in sequence: navigation, hero, features, pricing, and call to action.
4. Interrupt mid-paint and ask for a darker, more premium feel.
5. Select the hero and ask for a waitlist form.
6. End with the line: Codex becomes the brush, not the black box.
